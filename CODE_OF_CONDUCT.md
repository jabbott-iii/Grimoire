# Code of conduct

Grimoire adopts the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/), as its code of conduct. Read it at that address; this file doesn't copy it. It adds what the Covenant leaves to each project: where the code applies, how to report a problem, and what happens to a report.

## Where it applies

It applies to everyone who takes part, the maintainer included, in every project space: this repository, its issues, its pull requests and their reviews, its discussions, and any other space the project runs. It also applies when you represent the project elsewhere, for example when you speak for it in public.

## What happens to a report

- The maintainer reviews every report confidentially.
- Outcomes follow the Covenant's enforcement guidance.

## Reports about the maintainer

Grimoire has one maintainer, so there is no second person in the project to take a report about them. You can still send it to the contact above. You can also report the behaviour to GitHub with GitHub's report-abuse tools; GitHub reviews those reports under its own policies, not this project's. In a repository owned by a personal account, as this one is, those tools send the report to GitHub, not to the maintainer: GitHub's option to report content to a repository's maintainers is only for repositories owned by an organization.
